# keycrack

Every lock holds a key of four different symbols. Guess, read the feedback, cut down what is left.

## Play

https://dhellss.github.io/keycrack/

## Rules

- Feedback is unordered - it tells you how many, never which.
- Type the symbols on your keyboard, backspace to delete, enter to try.
- Eight attempts per lock.

## Built with

Plain HTML, CSS and JavaScript.
